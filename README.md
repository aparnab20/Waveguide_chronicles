# Waveguide_chronicles
Welcome to Waveguide Chronicles! A theory-meets-simulation archive exploring how classic waveguide behaviors change under geometric perturbations. Every structure—from simple twists and bends to flares, slots, ridges, and posts—is derived mathematically and verified through full-wave electromagnetic simulation.
## 📂 Repository Structure

The repository is organized by structural complexity. Each directory houses the simulation project files, analytical notes, and visual validation plots.

```text
Waveguide-Chronicles/
│
├── 01_Classic_Geometries/      # Rectangular, circular
├── 02_Twists_and_Bends/        # E-plane/H-plane bends, continuous twists
├── 03_Flares_and_Transitions/  # Horns, tapered impedance matchers
├── 04_Slots_and_Couplings/     # Iris, wall slots, directional couplers
├── 05_Ridges_and_Posts/        # Ridge waveguides, tuning posts, obstacles
└── assets/                     # Images, diagrams, and shared scripts
